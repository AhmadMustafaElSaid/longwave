# تشغيل Longwave

Longwave إضافة للمتصفح مع تطبيق محلي مرافق. يتولى التطبيق المحلي التنزيل وتجهيز الصوت، لذلك يستمر العمل بعد إغلاق نافذة الإضافة، ولا تحتاج الملفات الطويلة إلى البقاء كاملة داخل ذاكرة المتصفح.

الإصدار المرشح 0.2.0 يوفر حزمة مستقلة لـ Windows 10/11 ‏64-bit مع Chrome وEdge. لا تحتاج إلى Python أو Node.js أو ملفات المشروع. دعم الأنظمة الأخرى والتثبيت من المتاجر غير متاح حاليًا.

## التثبيت للمستخدم العادي

1. فك ضغط حزمة `longwave-0.2.0-rc.1-windows-x64.zip` كاملة.
2. افتح **Longwave-Setup.exe** واختر مجلد الصوت ثم اضغط **تثبيت / تحديث**.
3. افتح **START-HERE.html** واتبع خطوات تحميل مجلد الإضافة في المتصفح.
4. احتفظ بمجلد التثبيت داخل `%LOCALAPPDATA%/Longwave`. يمكنك حذف الحزمة التي نزّلتها بعد اكتمال التثبيت.

المثبّت لا يحتاج صلاحية مسؤول. توجد أزرار للتحديث واستعادة الإصدار السابق وفصل التطبيق دون حذف الصوت والسجل. الحزمة غير موقّعة بعد؛ رابط التنزيل العام يتطلب رفعها إلى صفحة إصدارات المستودع.

## التثبيت من المصدر

ثبّت Node.js 22 أو أحدث وPython 3.11 أو أحدث، ثم نفّذ الأوامر التالية من مجلد المشروع في PowerShell:

```powershell
npm ci
npm run setup:media
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --require-hashes -r companion\requirements.txt
npm run build
.\.venv\Scripts\python.exe scripts\install_companion.py
```

افتح `edge://extensions` أو `chrome://extensions`، فعّل وضع المطوّر، واختر **Load unpacked** ثم مجلد `dist/chromium`. افتح Longwave وتأكد أن الحالة «متصل».

احتفظ بمجلد المشروع وبيئة `.venv` في مكانهما؛ مشغّل نسخة التطوير يشير إليهما. التسجيل خاص بحسابك ولا يحتاج صلاحية مسؤول.

## الاستخدام

1. الصق رابط المقطع أو رسالة المشاركة التي تحتوي على رابط SoundCloud واحد.
2. اختر **صيغة المصدر** للحفاظ على الصوت المتاح دون إعادة ترميز، أو **MP3** لتوافق أوسع.
3. اضغط **تنزيل الصوت**. يمكنك إغلاق المتصفح ومتابعة الحالة لاحقًا من الإضافة.
4. بعد الاكتمال، اضغط **عرض في المجلد** وافتح الملف في مشغّلك المحلي. اختر سرعة 2× من المشغّل إن أردت.

لا يشترط وجود زر تنزيل أصلي في SoundCloud؛ النسخة تستخدم البث العام الكامل غير المشفّر حين يكون متاحًا. جودة هذا البث قد تختلف عن الملف الأصلي الذي رفعه صاحب المقطع، والتحويل إلى MP3 لا يضيف جودة مفقودة.

الإيقاف والاستئناف متاحان، لكن إذا تغيّر رابط البث الموقّع أو تعذّر التأكد من تطابق المصدر، يبدأ التنزيل من جديد بدل دمج بيانات غير مؤكدة. تُحفظ الأجزاء القديمة محليًا؛ لا توجد بعد واجهة تنظيف تلقائي لها.

مجلد الحفظ الافتراضي هو `Downloads/Longwave`. لتغييره، أعد تسجيل التطبيق مع الخيار التالي:

```powershell
.\.venv\Scripts\python.exe scripts\install_companion.py --output "D:\Audio"
```

استخدم نفس خيار `--home` إن كنت قد حدّدت مجلد بيانات مخصصًا عند التثبيت. بعد إعادة تشغيل الجهاز افتح الإضافة لاستعادة المهام؛ لا تُسجّل نسخة التطوير نفسها ضمن برامج بدء التشغيل.

## حالة الاختبار

اكتمل تنزيل مقطع اختباري بطول 7 ساعات و35 دقيقة تقريبًا مع تعطيل زر التنزيل الأصلي. حُفظ الصوت بصيغة M4A/AAC، وتحققنا من مدته وفك الصوت في بدايته ووسطه ونهايته. [تقرير التحقق](verification.md)

حُدّثت أدوات الوسائط إلى إصدار متطابق مثبت البصمة. يبقى توقيع المثبّت واختبار أجهزة مستقلة والنشر في المتاجر قبل الإصدار المستقر. بعض رسائل التشخيص ما زالت بالإنجليزية. راجع [التوزيع](distribution.md) و[حل المشكلات](troubleshooting.md).

احفظ الصوت الذي تملكه أو لديك إذن بالاحتفاظ به، واحترم حقوق النشر والتراخيص وشروط المنصة. الإتاحة العامة للاستماع لا تعني الإذن بالتنزيل. لا تتجاوز Longwave التشفير أو الاشتراكات أو ضوابط الوصول.
