# دليل Longwave

[حمّل النسخة العامة من GitHub](https://github.com/AhmadMustafaElSaid/longwave/releases/latest). ثبّت التطبيق المرافق على الحاسوب الذي سيحفظ الصوت، ثم أضف الإضافة إلى Chrome أو Edge.

| جهازك                      | خطوات التثبيت                                                                                                                                                           |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows ‏64-bit            | فك ضغط ملف `windows-x64.zip` كاملًا، وافتح **Longwave-Setup.exe**. اختر مجلد الصوت واضغط تثبيت. يوفر المثبّت Python وينزّل أدوات الصوت بعد التحقق من بصمتها.               |
| Ubuntu أو Debian           | نفّذ `sudo apt install ./longwave-0.3.0-all.deb` من مجلد التنزيل، ثم `longwave connect` من حسابك العادي.                                                                 |
| macOS أو توزيعة Linux أخرى | ثبّت Python 3.11 أو أحدث وFFmpeg. على macOS مع Homebrew استخدم `brew install python ffmpeg`. فك ضغط ملف `unix.tar.gz` في مجلد دائم ثم شغّل `./longwave connect` من داخله. |

1. افتح `chrome://extensions` أو `edge://extensions`، وفعّل وضع المطوّر ثم اختر **Load unpacked**.
2. حدّد مجلد الإضافة الذي يعرضه المثبّت أو أمر `connect`. في Windows يمكنك نسخ المسار من المثبّت.
3. افتح Longwave وتأكد من ظهور **متصل**. ألصق رابط المقطع أو رسالة المشاركة كاملة. اختر **صيغة المصدر** أو **MP3** واضغط **تنزيل الصوت**. يمكنك إغلاق المتصفح أثناء التنزيل.
4. افتح الملف في مشغّلك واضبط السرعة على 2×. يمكنك الإيقاف المؤقت والاستئناف من الإضافة. عند تغيّر المصدر قد يبدأ نقل جديد لضمان سلامة الملف.

## عندما يغيب زر التنزيل

تستطيع Longwave العمل إذا أتاح SoundCloud مسارًا صوتيًا كاملًا وعامًا وغير مشفّر. غياب زر التنزيل لا يثبت حق الاحتفاظ بنسخة. استخدمها للتسجيلات التي تملكها أو حصلت على إذن بحفظها وفقًا للترخيص وشروط المنصة. المقاطع الخاصة والمحمية والمقتطفات خارج نطاق الدعم.

## الاستخدام من الهاتف

يعمل الحاسوب على التنزيل والتحويل. استخدم هاتفك لإضافة المقطع أو تشغيله أو حفظ الملف للاستماع لاحقًا دون اتصال.

1. اربط الهاتف والحاسوب بشبكتك الخاصة. إن كنت تستخدم Tailscale، فشغّل `tailscale serve http://127.0.0.1:8765` على الحاسوب واتركه يعمل. انسخ عنوان HTTPS الذي يعرضه.
2. شغّل `longwave phone --origin https://YOUR-PRIVATE-HOST` من نافذة أخرى، واستبدل العنوان بعنوانك. في الحزمة المفكوكة استخدم `./longwave`، وفي Windows استخدم `Phone.cmd` داخل مجلد الإصدار المثبّت.
3. افتح العنوان على الهاتف وأدخل الرمز الظاهر على الحاسوب. الرمز صالح لعشر دقائق ويُستخدم مرة واحدة. للجهاز المقترن حق الوصول إلى قائمة التنزيلات والملفات المكتملة لمدة 12 ساعة. أغلق نافذة خدمة الهاتف لإنهاء الوصول فورًا.
4. اختر **حفظ على الهاتف** أو **تشغيل**، ثم اضبط السرعة. يبقى الحاسوب قيد التشغيل حتى يكتمل النقل إلى الهاتف.

تتضمن صفحة الإصدار بصمات SHA-256 وشهادة منشأ البناء. التثبيت من متجري Chrome وEdge وتوقيع نظام التشغيل باسم الناشر لهما حالة مستقلة موضحة في ملاحظات الإصدار. [التثبيت والتحقق](install.md) · [الدعم](https://github.com/AhmadMustafaElSaid/longwave/issues)
