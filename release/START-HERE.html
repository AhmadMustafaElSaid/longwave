Windows 10/11 · x64

longwave.

Long listens. Local files. No developer tools required.

  1. Extract the entire ZIP, then open Longwave-Setup.exe. Keep the payload folder beside it.
  2. Choose where audio is saved. Allow setup to fetch the verified audio tools, then select Install / update. Setup installs for your account; no administrator privileges are needed.
  3. Open edge://extensions or chrome://extensions. Enable Developer mode, choose Load unpacked, and paste the extension folder using setup's Copy path + open guide button.
  4. Open Longwave from your browser toolbar. Check for Connected, paste a SoundCloud track link, and download.

The extension folder is inside %LOCALAPPDATA%\Longwave\versions. Keep that installed folder in place. After installation you can move or remove the extracted download package.

Updating and recovery

Run setup from the next release to install it alongside the current version. Active downloads are paused. Load the new extension folder (remove the old unpacked entry if needed), then resume downloads in Longwave. Restore previous version switches the companion back and shows the earlier extension folder. No automatic updates run in the background.

Disconnect companion removes matching browser registration and stops work. Audio, history, partial data, and installed versions are kept. Remove the extension through the browser. You can delete %LOCALAPPDATA%\Longwave after disconnecting if you also want to remove that local data; keep any audio stored there first.

What this release supports

Public full-length clear audio, source-format output and optional MP3. A creator download button is not required. Resume is conditional on source identity; changed signed URLs can require restarting. Choose playback speed in your local player.

Find the other desktop packages, phone pairing instructions and file verification on the official release page.

دليل البدء

هذه حزمة مستقلة لـ Windows 10/11 ‏64-bit، ولا تحتاج إلى تثبيت Python أو Node.js.

  1. فك ضغط الحزمة كاملة ثم افتح Longwave-Setup.exe.
  2. اختر مجلد الصوت ووافق على تنزيل أدوات الوسائط، ثم اضغط تثبيت / تحديث.
  3. افتح edge://extensions أو chrome://extensions، فعّل وضع المطوّر واختر Load unpacked ثم الصق مسار الإضافة من زر نسخ المسار وفتح الدليل في المثبّت.
  4. افتح الإضافة وتأكد من ظهور «متصل»، ثم الصق رابط المقطع.

عند التحديث تتوقف التنزيلات مؤقتًا وتبقى ملفاتك محفوظة. حمّل مجلد الإضافة الجديد، ثم استأنف من الواجهة. زر استعادة الإصدار السابق يعيد التطبيق المرافق إلى النسخة السابقة. زر الفصل يوقف العمل ويلغي اتصال المتصفحات، دون حذف الصوت أو السجل.

تتوفر حزم Linux وmacOS ودليل ربط الهاتف على صفحة الإصدار.
